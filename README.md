### 🧑‍💻 Обо мне

Java-разработчик с фокусом на создание надёжных и производительных бэкенд-систем.  
В ежедневной работе использую **Java 17+**, **Spring Framework** (Boot, Cloud, Data, Security), **Apache Kafka**, **PostgreSQL**, **Docker** и **Kubernetes**.  
Мониторинг и observability строю с помощью **Grafana** + Prometheus.

Также имею опыт с **C++** (высокопроизводительные модули) и **Python** + **Django** (быстрые прототипы и внутренние инструменты).
